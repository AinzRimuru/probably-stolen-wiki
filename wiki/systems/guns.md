# 枪支打印 > 通过 3D打印机 + 打印芯片自制枪械、枪械框架、零件与改装件，再通过枪械订单（GunOrder）交付客户赚取赏金的完整"造枪—卖枪"产业链。 --- ## 系统总览 1. **获取设备**：网络升级"退休枪匠"（650cr）赠送破旧 3D打印机（含100电能电池与 .22手枪芯片），退休枪匠此后每周到访出售芯片、模组与材料。
2. **打印**：打印机芯片槽放芯片（不消耗、可复用）→ 输入托盘放材料 → 电池槽放电池 → 每个游戏日推进进度，完成后产物落入输出区。
3. **组装**（框架路线）：打印枪械框架 → 拖 1 个枪械零件到框架上 → 组装成整枪（状态全新、属性受打印品质加成）。
4. **改装**：给枪装改装件（弹匣/枪管/导轨/下挂/枪托/特殊×3）满足订单属性要求。
5. **交付**：枪械订单客户上门 → 把达标的枪放到柜台成交 → 获得赏金（含奖金与市场加成），并可能追加弹药/近战/军械订单。 --- ## 机器与设备 | 中文名 | 英文ID | 基准价 | 耗电 | 用途 |

- 打印机 `品质系数 = 4`；**打印品质 = 模组总质量加成 ÷ 4**。
- 直接打印的枪：六维 × (100 + 打印品质) / 100（`BaseStat`）。例：质量模组+8% → 品质2 → ×102%；精细模组+25% → 品质6 → ×106%。
- 打印的框架：品质 = 打印品质 + 锭纯度加成（托盘中所有金属锭纯度加成的平均值），组装枪同样按上式乘算且状态固定全新。 ### 金属锭纯度（IngotPurityHelper）
| 纯度 | 零件产量 | 品质加成 | 锭价值修正 |
|---|---|---|---|
| 极低 | 2 | -30 | -25% |
| 低 LOW | 3 | -20 | -15% |
| 一般 | 3（默认） | 0 | 0 |
| 高 | 4 | +20 | +25% |
| 极高 | 4 | +30 | +50% |
| 完美 | 5 | +100 | +200% | ### 枪械当前属性公式
`当前值 = 基础值 × (100 + 状态修正 + Σ改装件百分比) / 100 + Σ改装件固定值`（整数除法）
状态修正：全新+30 / 优秀+15 / 良好0 / 一般-15 / 差-30。大小= 物品占格数。 ### 打印速度与耗电
- 速度 = 24 + 24×性能%/100（金属/CNC/批量模组为负性能会拖慢）；耗时=ceil(工作量÷速度)天。
- 耗电 = 8 - 8×效率%/100（最低1）× 天数；电力不足当日不推进。开印当日即扣电并计1天进度。 ### 近战打印状态roll（供参考）
`RNG(20~30) + 打印品质 + 锭纯度加成`：<25 差 / <60 一般 / <90 良好 / ≥90 优秀；批量模组每件+1产出。 ### 违禁与热度
- 自制枪全部为违禁品：解放者/巢火=低级(1)；铁铸10/哨兵3型/左轮/两框架=中级(2)；和平使者/壁垒=高级(3)。穿甲弹=中级，普通弹=低级，非致命弹无标记。
- 向不合适的客户出售违禁枪/假弹药盒会触发安全系统记账与声望损失；StolenHelper 的"失窃热度"只作用于偷来的物品，与打印枪无关。
- 武器许可证 I/II/III（网络升级）提高退休枪匠出售高级芯片/模组的概率（II、III 各使 CNC/金属/批量模组与框架/零件芯片等概率 +15% 或 +10%）。 ### 退休枪匠进货（每周）
